# ととのね 家族グループ機能 仕様書

Sep 29, 2026 · @Yasuaki Takei

家族4人までが「毎日の習慣」と「お金の習慣（資産運用の習慣）」を見せ合い、習慣が身についていく過程を称え合う機能です。順位は付けず、食卓の会話のきっかけをつくることを目的とします。アプリ独自の家族グループ（Firebase）で実装し、iPhone・Mac・将来のAndroidをまたいで使えるようにします。

## 利用の流れ

代表者がグループを作り、招待コードで家族を迎え入れます。各自が共有する習慣を選んだら、家族ボードで見せ合える状態になります。

&#91;embedded content: 家族グループの利用の流れ · 5ステップ\]

1人が入れるグループは1つだけです。別のグループに入るときは、今のグループを抜けてから参加します。

## 招待と参加

招待は6桁のコードで行います。リンクよりも、食卓で口頭で伝えたりLINEで送ったりしやすいためです。

| 項目 | 仕様 |
| --- | --- |
| グループの作成 | 設定画面の「家族と共有」から代表者が作成。グループ名を付ける（例：○○家） |
| 招待コード | 6桁の数字。48時間で失効し、代表者はいつでも再発行できる |
| 共有の手段 | コードをOS標準の共有機能で送る（LINE・メッセージなど） |
| 参加 | 家族は設定画面でコードを入力し、表示名を決めて参加する |
| 人数の上限 | 代表者を含めて4人。4人そろうとコードは無効になる |
| 脱退 | メンバーはいつでも自分で抜けられる。代表者はメンバーを外せる |
| 代表者の交代 | 代表者が抜ける前に、別のメンバーに代表を引き継ぐ |

**技術メモ：** 招待リンクによく使われていたFirebase Dynamic Linksは提供が終了しているため使いません。将来リンク招待を足す場合は、ユニバーサルリンク（iPhone）とApp Links（Android）で実装します。途中で脱退しても、本人の習慣の記録はそのまま残ります。

## 共有範囲とプライバシー

家族に見えるのは「毎日の習慣」と「お金の習慣」だけです。その中でも、本人が習慣ごとに見せるかどうかを選べます。

| データ | 家族に見えるか |
| --- | --- |
| 毎日の習慣の名前 | 見える（「家族に見せる」がオンのものだけ） |
| お金の習慣の名前 | 見える（「家族に見せる」がオンのものだけ。初期設定はオフ） |
| 今日（今週・今月）やったかどうか | 見える |
| 連続日数（連続週数・連続月数） | 見える |
| 習慣化ステージ・節目 | 見える（「習慣化の共有」の章） |
| タイマーの時間・累計時間・距離・歩数 | 見えない |
| やめたい習慣 | 見えない（設定でも変えられない） |
| 余裕メーターの金額 | 見えない（設定でも変えられない） |
| 金額・資産額・評価損益・銘柄・口座 | 見えない（そもそもアプリに記録しない） |
| ひとことメモ | 見えない |

- 毎日の習慣の「家族に見せる」の初期設定はオン。お金の習慣は、習慣名だけでも家計の事情が伝わることがあるため初期設定はオフ。どちらも習慣の編集画面でいつでも切り替えられる
- オフにした習慣は、家族ボードからすぐに消える
- 未成年の家族が参加する場合は、保護者の同意を得たうえで使う前提とし、プライバシーポリシーに明記する

## 家族ボードの画面

下部メニューに「家族」タブを追加します（ホーム／履歴／家族／設定）。グループに入っていない人には表示しません。見た目は既存の「履歴」画面のカードデザインにそろえます。

```markdown
FAMILY
今日のととのい。          9月29日（火）

┌ お父さん ─────────────────┐
│ ✓ 読書            12日継続      │
│ ○ ランニング                     │
│ ［すごい］［おつかれさま］［いっしょに］ │
└─────────────────────────┘
┌ お母さん ─────────────────┐
│ ✓ ストレッチ       5日継続      │
│ もらった声：すごい（お父さん）      │
└─────────────────────────┘
```

| 要素 | 仕様 |
| --- | --- |
| 見出し | 「今日のととのい。」と日付。日付の左右で前日・翌日に切り替え |
| みんなの習慣 | 家族の共通習慣がある場合、カード群の上に表示（「習慣化の共有」の章） |
| 家族ごとのカード | 表示名、共有している毎日の習慣、今日の達成（✓／○）、連続日数、習慣化ステージ |
| お金の習慣 | 家族ごとのカードの下段に「お金の習慣」として区切って表示。今週・今月の達成と連続週数・月数（「資産運用の習慣の共有」の章） |
| 並び順 | 自分が先頭、残りは参加順。達成数などでは並べない |
| 称え合うボタン | 他の家族のカードにだけ表示（次の章） |

**表示しないもの：** 順位、達成率の比較、家族全体の合計点。続かなかった日を責めるような表現（赤色や「未達成」の文字）も使いません。

## 称え合う仕組みと通知

自由な文章のコメント機能は付けず、決まった3種類の声かけだけにします。言葉選びに迷わず送れ、言い合いにもならないためです。

| 声かけ | 使う場面 |
| --- | --- |
| すごい | 連続日数が伸びているとき |
| おつかれさま | 今日の習慣をやり終えたとき |
| いっしょに | まだやっていない習慣を、一緒にやろうと誘うとき |

- 声かけは「人×習慣×1日」につき各種類1回まで
- 受け取った声かけは、自分のカードに「もらった声」として表示する

**通知（Firebase Cloud Messaging）：** 通知が多いと家族の負担になるため、次の2種類に絞ります。

1. **声かけを受け取ったとき：** 「お父さんから『すごい』が届きました」
2. **1日1回のまとめ（夜）：** 「今日の家族のととのい：3人が習慣を達成」

どちらも設定画面で個別にオフにできます。家族の達成をその都度知らせる通知は、焦りを生むため作りません。

## 習慣化の共有

「今日やったか」だけでなく、習慣が**身についていく過程**を家族で見守れるようにします。結果ではなく過程を称えることで、続かなかった日があっても戻ってきやすくします。

### 習慣化ステージ

習慣ごとに、身につき具合を4段階で表示します。

| ステージ | 目安（これまでに実施した日数） | 家族ボードでの表示 |
| --- | --- | --- |
| はじめた | 1〜6日 | 「はじめた」 |
| 続いている | 7〜20日 | 「続いている」 |
| なじんできた | 21〜65日 | 「なじんできた」 |
| 身についた | 66日〜 | 「身についた」 |

- ステージは**連続日数ではなく、これまでの実施日数の合計**で決める。1日休んでもステージは下がらない
- 66日は、習慣が自動化するまでの期間を調べた研究（ロンドン大学 Lally ほか、2009年）の中央値に基づく。個人差が大きい（18〜254日）ため、画面では「目安」と表記する
- 週・月単位のお金の習慣は、実施回数で「1〜2回／3〜5回／6〜11回／12回〜」を目安とする（案）

### 節目のお祝い

実施日数が 7・21・66・100日に達したとき、家族ボードのカードに「節目」を表示します。

- 新しい通知の種類は増やさず、夜のまとめ通知に含める（例：「お母さんの『ストレッチ』が21日目になりました」）
- 日曜の家族ボードの上部に、その週に節目を迎えた習慣を一覧で表示する（人数や合計点は出さない）

### 再開の後押し

連続が途切れたあとに再び実施した日は、カードに「再開」と表示します。途切れた日数や「リセット」といった表現は使いません。声かけは既存の「おつかれさま」をそのまま使えます。

### みんなの習慣（家族の共通習慣）

家族で同じ習慣に取り組めるようにします（例：夕食後に10分片付け、寝る前にスマホを置く）。

| 項目 | 仕様 |
| --- | --- |
| 作成 | どのメンバーでも作成できる。グループで最大3つまで（案） |
| 参加 | 各メンバーが自分で「参加する」を選ぶ。参加しない自由を残す |
| 表示 | 家族ボード上部に、参加者ごとの今日の達成（✓／○）を並べる |
| そろった日 | 参加者全員が達成した日を「そろった日」として**累計**で数える。連続日数にはしない |
| 削除 | 作成者または代表者が削除できる。各自の記録は個人の習慣として残る |

**表示しないもの：** だれが達成していないかを強調する表示、「あと1人」のような催促の表現。

## 資産運用の習慣の共有

家族で共有するのは**お金との向き合い方の習慣**だけです。金額・資産額・損益・銘柄・口座はアプリに記録もせず、共有もしません。「いくら増えたか」ではなく「続けているか」を称え合うことで、家族でお金の話をするきっかけをつくります。

### 対象となる習慣（テンプレート）

習慣の追加画面に「お金の習慣」の区分を設け、次のテンプレートを用意します。自由に名前を付けた習慣も作れます。

| 習慣の例 | 頻度 |
| --- | --- |
| 家計簿をつける | 毎日 |
| 使ったお金をふりかえる | 毎週 |
| 子どものおこづかい帳をつける | 毎週 |
| 積立（NISAなど）の設定と明細を確認する | 毎月 |
| 家族でお金の話をする（家族マネー会議） | 毎月 |

- お金の習慣に限り、頻度を「毎日／毎週／毎月」から選べる。週は月曜はじまり、月は1日はじまり
- 家族ボードでは「今週 ✓」「今月 ✓」と表示し、連続は「6か月継続」のように週数・月数で数える
- お金の習慣は余裕メーターとは連動させない（金額が推測されるのを防ぐため）

### 家族の目標（任意）

「家族旅行の積立」のように、家族で目指す目標を1つ登録できます。

- 表示するのは**目標名と、参加メンバーが今月の積立を実施したかどうか**だけ。金額・達成率は表示しない
- 目標の達成は、代表者が「達成した」を押して記録する（家族ボードでお祝いを表示）

### 子どもの参加

- 未成年のメンバーが使えるお金の習慣は、おこづかい帳・ふりかえりなどの記録系のみとする
- 高校の家庭科で資産形成を扱うようになった（2022年度から）こともあり、家族マネー会議を「学びの場」として使えるよう、会議の話題の例をアプリ内で紹介する（案）

### 表現と法令上の注意

- 特定の金融商品・銘柄をすすめたり、売買の時期を助言したりしない（投資助言にあたらないようにするため）
- 証券口座や銀行口座との連携は、この機能の範囲外とする
- 「増える」「儲かる」など、成果を約束する表現は使わない
- 上記の線引きは、リリース前に法務・専門家に確認する（未確認）

## データ構造とセキュリティ

個人の習慣データはそのままにし、共有がオンの毎日の習慣だけを、家族用の場所に「写し」として書き出します。家族はこの写ししか読めないため、やめたい習慣や金額が漏れることはありません。

```
families/{familyId}
  name, ownerUid, memberUids[最大4], plan, createdAt

families/{familyId}/members/{uid}
  displayName, role（owner / member）, joinedAt

families/{familyId}/days/{yyyy-mm-dd}/entries/{uid_habitId}
  uid, habitName, done, streak, totalDays, stage, resumed, commonHabitId?, updatedAt

families/{familyId}/periods/{yyyy-Www | yyyy-mm}/entries/{uid_habitId}
  uid, habitName, category（money）, cycle（weekly / monthly）, done, streak, totalCount, stage, updatedAt

families/{familyId}/days/{yyyy-mm-dd}/cheers/{fromUid_toUid_habitId_type}
  fromUid, toUid, habitId, type（sugoi / otsukare / issho）, createdAt

families/{familyId}/commonHabits/{commonHabitId}
  name, createdBy, participantUids[], togetherDays, createdAt

families/{familyId}/goals/{goalId}
  name, participantUids[], achievedAt?, createdAt

invites/{code}
  familyId, expiresAt

users/{uid}/habits/{habitId}
  （既存）＋ shareWithFamily: true / false
          ＋ category: daily / money
          ＋ cycle: daily / weekly / monthly（money のみ weekly・monthly を選べる）
```

**セキュリティルールの原則：**

- `families` 以下は、`memberUids` に含まれる人だけが読める
- `entries` は、本人（`uid` が一致）だけが書ける
- `entries` に書き込めるフィールドは上記の一覧だけに制限する（`keys().hasOnly(...)`）。金額などの項目が誤って家族側に書き出されることを、ルールの段階で防ぐ
- `commonHabits` と `goals` の `participantUids` は、各メンバーが自分のuidの追加・削除だけできる
- `cheers` は、送り主本人だけが作成でき、自分宛てには送れない
- `users/{uid}` は、これまでどおり本人しか読めない

**参加処理：** 「4人まで」を確実に守るため、参加はサーバー側の処理（Cloud Functionsの`joinFamily`）で行い、同時に複数人が参加しても人数が超えないようにします。Cloud Functionsには従量課金プラン（Blaze）への切り替えが必要ですが、月200万回までの呼び出しは無料枠に収まります。予算アラートを設定しておくと安心です。

## 課金との関係

家族共有は有料機能ですが、課金が止まっても記録は奪いません。

| 状態 | 家族グループの動き |
| --- | --- |
| 代表者の登録から90日間 | 全員が無料で使える |
| 代表者が家族プランに課金中 | 全員が使える（他のメンバーは課金不要） |
| 90日経過後に課金していない | 家族ボードは「一時停止」。これまでの記録は見られるが、新しい更新と声かけは止まる |
| 課金を再開 | すぐに元に戻る。グループもメンバーもそのまま |

- 課金状態はサーバー側で確認し、`families/{familyId}` の `plan` に反映する
- 各メンバーの個人の習慣記録は、課金状態に関係なく使い続けられる
- 一時停止の画面では、責める表現を避け「家族との共有を再開しますか」と案内する
